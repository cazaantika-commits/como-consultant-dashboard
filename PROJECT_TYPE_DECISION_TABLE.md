## Decision sequence

1. Complete the **Build for sale** column first, one item at a time.
2. Approve the resulting rule set before changing any current project or report.
3. Complete the **Build for rent** column separately; its revenue rules must be defined independently from sales rules.
4. Only then create a new project-type selector that applies these approved rules automatically in Feasibility, Investor Cash Flow, and Escrow Cash Flow.
