# الموسوعة النهائية الشاملة لنطاق التصميم

## القاعدة المعتمدة

هذه الموسوعة هي قائمة تصميم شاملة تصلح للمشروع الصغير أو الكبير. تحتوي على **42 بندًا مستقلًا** مرتبة من الخدمات الأساسية إلى الخدمات المتخصصة. لا يعني وجود البند في الموسوعة أنه مطلوب في كل مشروع؛ عند إنشاء المشروع يحدد المالك حالة كل بند بصورة مستقلة: **مطلوب، غير مطلوب، أو غير منطبق**.

لا تشمل الموسوعة أعمال الإشراف، أو القوانين والشروط التعاقدية، أو التأمينات، أو الاحتياطيات التجارية. كما استُبعدت الخدمات التي قرر المالك أنها تُتعاقد وتُدفع مباشرةً بمعزل عن استشاري التصميم.

| إدارة التكلفة والاستشارات التكاليفية | تعاقد مباشر للمالك، خارج نطاق استشاري التصميم. |
| شهادات LEED / WELL أو أي شهادة استدامة اختيارية | تعاقد اعتماد مستقل للمالك، خارج نطاق الاستشاري. |
| تنسيق أعمال تجهيزات المستأجرين أثناء الإنشاء | عمل تنفيذي/إشرافي بعد التعاقد، خارج مصفوفة التصميم. |
| جميع أعمال وأدوار الإشراف | لها مصفوفة مستقلة ولا تدخل في موسوعة التصميم. |
| القوانين والشروط والتأمينات والاحتجاز وسقف الأتعاب | شروط تعاقدية وليست خدمات تصميم. |
| الاحتياطيات التجارية وأسماء الأفراد ومددهم | عناصر تسعير وموارد داخل عرض الاستشاري وليست خدمات نطاق مستقلة. |

## طريقة استخدام الموسوعة لكل مشروع

| الحقل | القيم أو الوظيفة |
|---|---|
| حالة البند | مطلوب / غير مطلوب / غير منطبق |
| جهة التنفيذ | الاستشاري الرئيسي / متخصص يرشحه الاستشاري / جهة يعيّنها المالك |
| المدة | قيمة ووحدة قابلة للتعديل عند ارتباط الخدمة بمدة |
| قيمة الفجوة | قيمة مرجعية قابلة للتعديل تُضاف عند غياب البند من عرض الاستشاري |
| ملاحظات المشروع | مخرجات وحدود خاصة بالمشروع دون تغيير الموسوعة العامة |

> **القاعدة:** كل مشروع يملك نسخة مستقلة من البنود الاثنين والأربعين. تعديل مشروع لا يغيّر مشروعًا آخر ولا يغير الموسوعة الشاملة. المقارنة مع عروض الاستشاريين تستخدم البنود المحددة «مطلوب» في المشروع فقط.
