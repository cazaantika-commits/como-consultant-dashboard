# Marketing Start Enforcement Verification

Project verified: **مجان متعدد الاستخدامات (G+4P+25)**.

The Settings-derived marketing start is project month 6. On the Marketing page, the start field displays **6** as read-only; the allocation grid begins in month 6 and has no editable columns for months 1–5. The saved distribution is AED 487,608 per month from months 6–22.

Investor Cash Flow displays the `التسويق` row as zero in design months 1–5, then AED 488K in design months 6–7 and the following construction months through project month 22. This is the displayed rounding of the Marketing page’s saved allocation and confirms that no marketing expense is reflected before the permitted start month.
